# 蓝军挑战报告:对"red-team-challenge skill 升级建议"的自挑战(dogfood)

模式:想法模式 ｜ 日期:2026-06-20 ｜ 挑战对象数:8 条升级建议(R1–R8)+ 6 条方法论引用 ｜ 手段:4 个独立对抗子代理(事实核查 + 对手/用户/资源三视角)+ 主会话复核闸门(2 次来源抽查)

> 本报告是用现版 `red-team-challenge` skill 挑战它自己的升级建议而产出的。攻击者立场:这套升级是过度设计,会把一把快刀改钝,直到证明自己不是。

## 一、致命问题(Showstoppers)

- 🔴 **承重假设被打穿:"服务好'找可优化点'与'反哺'两个目标 = 给 skill 增加步骤/产物。"** 证据一致指向反面——高价值修法都是**便宜的**(复用已有机制、报告加字段、磨利已有视角);而昂贵的新增(R4 全🟢增效 pass、R6 开放循环、R8 普查、R5 台账、R7 阻塞式契约)是净负:把"快、轻、单一职责"的对抗刀改造成"重、慢、多产物、要维护"的流程框架,而所有先例都显示轻量工具一旦仪式化就被弃用。见 #R4 #R5 #R7 与第六节事前验尸。
- 🔴 **我引用的两处"权威背书"经核查不实**:华为蓝军"采纳率考核"(无据,系自加)、"steelman-delta 是已确立的命名方法"(查无此词,系自造)。见 #C1 #C6。

## 三、盲区与遗漏(D)

- **我原评审只做了"加法",没做"减法预算"。** 8 条建议无一条评估"它要花多少子代理/token/延迟"——资源视角整段是现版 skill 自己从不提示的盲区(skill 派子代理时无任何成本意识)。
- **没区分"目标"与"机制"。** 用户的两个目标(找可优化点、反哺)是真需求;但我把它们和具体机制(增效 pass、台账、契约)捆死,导致机制被打穿时显得目标也一起塌。实际上目标可用便宜得多的机制达成。
- **未考虑产物介质的约束。** 报告是静态 md 这一事实,直接判了 R5 状态列、R7 阻塞契约的死刑——我提建议时没把"介质决定可行性"算进去。

## 四、可行性拷问(C)

- **认知负荷/token 预算**:把"检测+增效+CAPA+决策+台账+自检"全塞进一个 SKILL.md,会与"token 高效 skill"原则冲突,并因条件分支过多(承重/抽检/loop 上限/按需开关)抬高主会话漏执行概率。可行解:核心只保留零成本项默认生效,昂贵项写进 `references/` 按需加载。
- **采纳率 KPI 不可行且有害**:已述,制造反向激励。

## 五、总评

- **一句话结论**:8 条建议**无一条按原样可取**;3 条🔴(R4/R5 + C1/C6 引用)、4 条🟡、1 条🟢,共性病根是"用加法服务目标"。能进 skill 的只有**便宜版**:复用已有机制 + 报告加字段 + 磨利已有视角。
- **整体可信度评级(对"这组增量利于 skill"这一主张)**:**低**。
- **最该先做的 3 件事**:
  1. **把目标②(反哺)用最便宜方式落地**:文档模式补"反哺/验-判据"字段 + 现有"对手视角"显式输出"更优解"一行——同时服务目标①②,近零成本。这是唯一的"keeper"。
  2. **砍掉一切净增子代理/死产物/阻塞步骤**:R4 增效 pass、R5 状态列+采纳率、R7 阻塞契约、R8 普查、R6 开放循环——要么改按需进 references,要么删。
  3. **不要碰复核闸门**:它在本次 dogfood 里两次拦下对抗子代理的过度证伪(over-cite growthemind、虚增华为 counter-detail),已自证价值;任何升级不得稀释它。

## 六、事前验尸结论(假设这组增量原样上线、一年后 skill 被弃用)

- **最可能的死因(Top 3)**:
  1. **R7 前置契约**让"随手扔进去"变成"先回答 3 个问题",高频轻量场景嫌烦→用户退回"自己随便看",启动摩擦杀死复用频率。
  2. **R5 状态列**从没人填过一次"已闭环",报告里一片"待办"→自我感动的死字段,用户察觉"这工具让我背了个没人维护的台账",信任下降。
  3. **R4+R6+R8 叠加**,每次运行从"快"变"等很久还啰嗦"→在"只想快速找个茬"的场景被绕过,久而久之弃用。
- **最该先做的一个验证实验**:取一份真实文档,跑"现版 skill" vs "只加便宜版反哺(文档模式 验-判据 + 对手视角输出更优解)"两版,比较**(a)是否多产出了可优化点、(b)耗时/子代理数是否基本持平**。只验这一条最便宜、最致命的假设——若便宜版就能补上目标①②,则所有昂贵升级(R4/R5/R6/R7/R8)无须再议。
